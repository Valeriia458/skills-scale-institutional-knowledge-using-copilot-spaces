# OctoAcme Project Management Docs

A central README that summarizes OctoAcme's project management processes and links to the full set of process documents. Use this as an onboarding and reference page.

## Summary
OctoAcme uses a lightweight, iterative project management approach focused on clear ownership, measurable outcomes, and continuous improvement. Core elements:

- Roles: Project Manager (PM), Product Manager (PdM), Developers, QA/Testing, Stakeholders
- Team rhythm: daily standups, weekly delivery syncs, sprint demos/reviews
- Workflows: prioritized backlog, small PRs, CI checks, branch & PR conventions
- Planning & execution: kickoff, backlog refinement, sprint planning, Definition of Done (DoD), acceptance criteria
- Release & deployment: pre-release checks, staging & smoke tests, rollback plan
- Risk & communication: maintain a risk register, weekly status updates, escalation paths
- Retrospectives: capture action items and track improvements
