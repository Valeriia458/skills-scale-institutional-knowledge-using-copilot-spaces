# Sprint / Iteration Planning Checklist

Use this checklist during sprint or iteration planning to ensure work is ready, scoped, and assigned.

- [ ] Backlog groomed and prioritized
- [ ] Items selected meet the Definition of Ready (DoR)
- [ ] Acceptance criteria documented for each item
- [ ] Estimates provided (story points or T-shirt sizing)
- [ ] Owners assigned for each backlog item
- [ ] Dependencies identified and owners noted
- [ ] Test/QA approach noted for each item
- [ ] Required design or research artifacts attached
- [ ] Performance, security, and compliance considerations identified
- [ ] Team capacity checked against planned work
- [ ] Non-functional requirements and instrumentation needs noted
- [ ] Release/rollback impact assessed (if applicable)

Notes:
- Pull items only when they meet DoR and have clear acceptance criteria.
- Track unresolved dependencies as risks and assign owners.
